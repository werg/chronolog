# `@chronolog/materializer`

Deterministic Chronolog topic kernel (`state/v3`), scoped QuickJS-NG WASM ESM sandbox, pure WebAssembly sandbox, derivation evaluator, and audited standard modules.

## Exports

- **`TopicKernel` (`kernel.ts`):** Flat timestamp-ordered O(changed) suffix-replay engine enforcing the two-way public/encrypted control partition, fail-closed `$admission.authorize()`, optional cross-topic `$admission.verify()`, kernel-enforced monotonic `$seals` (reducer hash + transitive import locks and `frozen`/`append-only` JSON paths), compartment `$keys.topicRings` isolation, `simulate()`, rolling `historyDigest`, per-topic `stateRoot` (`state/v3`), `revision.digest`, `query()`, `describe()`, `signalPolicy()`, `createAdmissionEvaluator()`, historical reducer root pinning, and `bootstrapFromCheckpoint()`.
- **`QuickJsSandbox` (`quickjs-sandbox.ts`):** Fresh `QuickJSContext` per invocation with deep-frozen inputs (`state`, `tx`, `ctx.config`, `ctx.topic()`), `ctx.can()` and `ctx.reject()` (`reducer:crash` vs intentional rejection), 2-argument scoped `chronolog-pkg/v1` module loader (diamond-dependency isolation + per-package `builtins` attenuation), lazy `readTopic` host reads, deterministic fuel metering (`limits.maxFuel`), uncatchable host-level `MissingDependencyError`, static `WebAssembly.Module` support, `ctx.mount()`/`ctx.mountQuery()`, and `chronolog:crypto` (`crypto@2`: SHA-256, HMAC-SHA256, Ed25519, P-256 WebAuthn) / `chronolog:cas` / `chronolog:sqlite` / `chronolog:wasm` builtins.
- **`WasmSandbox` (`wasm-sandbox.ts`):** Pure deterministic WebAssembly runtime (`runtime: 'wasm-pure'` `chronolog-wasm/v1` ABI + `chronolog:wasm` `invoke`/`invokeJson`) with per-hash compiled `WebAssembly.Module` caching and zero non-`chronolog` host imports.
- **Derivations & Attestations (`derivation.ts`):** `evaluateDerivation()`, `verifyDerivationOutput()`, `createBytesStoreDerivationMemo()`, and Ed25519 `chronolog-attestation/v1` build/audit sign & verify helpers.
- **Standard Modules (`@chronolog/materializer/std-modules`):** `STANDARD_MODULE_SOURCES`, `STANDARD_MODULE_IMPORTS`, `seedStandardModules()`, and `seedStandardPackages()` covering all 23 audited modules: `chronolog/{admission,seals,reducer,keys,vaults,publications,mounts,builders,registry,sql,rls,sqlite-helpers,guards,quotas,queue,votes,schema,audit,crdt,text,ledger,workflow,fs}`.
